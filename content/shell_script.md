## 1. 脚本基础

### 脚本首行 (Shebang)

> 脚本第一行，用 `#!`（shebang）指定用哪个解释器执行。

- 语法:`#!/bin/bash`
- 常见写法:

| 写法 | 说明 |
|------|------|
| `#!/bin/bash` | bash 解释器（最常用） |
| `#!/bin/sh` | sh 解释器（更兼容，功能少） |
| `#!/usr/bin/env bash` | 从 PATH 里找 bash（更可移植） |

- 示例:

```bash
#!/bin/bash
echo "hello"
```

### 定义变量

> 自定义变量，注意 `=` 两边不能有空格。

- 语法:`变量名=值`
- 命名规则:字母或下划线开头，只能含字母、数字、下划线，区分大小写
- 只读变量:`readonly 变量名=值`，定义后不能再修改
- 示例:

```bash
name="zhangsan"
age=18
dir=/home/user
readonly PI=3.14          # 只读变量，之后不能改
```

## 2. 运算符

### 算术扩展

> 用 `$(())` 做整数算术运算，结果可直接输出或赋值给变量。

- 语法:`$((表达式))`，例如 `echo $((1 + 2))`
- 常用运算符:`+` 加 · `-` 减 · `*` 乘 · `/` 除 · `%` 取余 · `**` 幂
- 示例:

```bash
a=10
b=3
echo $((a + b))      # 13  加
echo $((a - b))      # 7   减
echo $((a * b))      # 30  乘
echo $((a / b))      # 3   整数除法
echo $((a % b))      # 1   取余
echo $((a ** 2))     # 100 幂
```

### 算术运算

> `$[]` 是 `$(())` 的旧写法，功能相同，现已不推荐使用。

- 语法:`$[表达式]`，例如 `echo $[1 + 2]`
- 说明:与 `$(())` 等价，可读性差且部分新环境可能不兼容，建议改用 `$(())`
- 示例:

```bash
a=10
b=3
echo $[a + b]        # 13
echo $[a * b]        # 30
echo $[a % b]        # 1
```
