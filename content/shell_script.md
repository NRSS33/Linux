## 1. 脚本基础

### 脚本首行 (Shebang)

> 脚本第一行，用 `#!`（shebang）指定用哪个解释器执行。

- 语法:`#!/bin/bash`
- 常见写法:

| 写法 | 说明 |
|------|------|
| `#!/bin/bash` | bash 解释器（最常用） |
| `#!/bin/sh` | sh 解释器（更兼容，功能少） |
| `#!/usr/bin/env bash` | 从 PATH 里找 bash（更可移植） |

- 示例:

```bash
#!/bin/bash
echo "hello"
```

### 定义变量

> 自定义变量，注意 `=` 两边不能有空格。

- 语法:`变量名=值`
- 命名规则:字母或下划线开头，只能含字母、数字、下划线，区分大小写
- 只读变量:`readonly 变量名=值`，定义后不能再修改
- 示例:

```bash
name="zhangsan"
age=18
dir=/home/user
readonly PI=3.14          # 只读变量，之后不能改
```

### 获取变量值

> 用 `$` 读取变量的值。

- 语法:`$变量名` 或 `${变量名}`
- 常用特殊变量:`$0` 脚本名 · `$1` 第1个参数 · `$#` 参数个数 · `$?` 上条命令退出码 · `$$` 当前进程 PID
- 示例:

```bash
echo $name
echo "${name}abc"       # 花括号界定变量名，避免歧义
echo "第一个参数: $1"
```

### read 读取输入

> 从标准输入读取一行内容并赋值给变量，脚本里常用于读取用户输入。

- 语法:`read [选项] 变量名`
- 常用选项:`-p` 显示提示文字 · `-r` 原样保留反斜杠 · `-s` 隐藏输入(密码) · `-n` 只读 N 个字符 · `-t` 超时秒数 · `-a` 按空格拆分成数组
- 示例:

```bash
read name                       # 读取一行到变量 name
read -p "用户名: " user          # 带提示文字读取
read -s -p "密码: " pwd          # 隐藏输入(不回显)
read -r line                    # 保留反斜杠,不解析转义
read -n 1 -p "继续?(y/n) " ans  # 只读 1 个字符,不用按回车
read -t 5 ans                   # 5 秒内没输入就超时
read -a arr                     # 按空格拆分成数组
```

## 2. 运算符

### 算术扩展

> 用 `$(())` 做整数算术运算，结果可直接输出或赋值给变量。

- 语法:`$((表达式))`，例如 `echo $((1 + 2))`
- 常用运算符:`+` 加 · `-` 减 · `*` 乘 · `/` 除 · `%` 取余 · `**` 幂
- 示例:

```bash
a=10
b=3
echo $((a + b))      # 13  加
echo $((a - b))      # 7   减
echo $((a * b))      # 30  乘
echo $((a / b))      # 3   整数除法
echo $((a % b))      # 1   取余
echo $((a ** 2))     # 100 幂
```

### 算术运算

> `$[]` 是 `$(())` 的旧写法，功能相同，现已不推荐使用。

- 语法:`$[表达式]`，例如 `echo $[1 + 2]`
- 说明:与 `$(())` 等价，可读性差且部分新环境可能不兼容，建议改用 `$(())`
- 示例:

```bash
a=10
b=3
echo $[a + b]        # 13
echo $[a * b]        # 30
echo $[a % b]        # 1
```

## 3. 语法

### 数值比较

> 在 `[ ]` 或 `[[ ]]` 里比较两个整数，条件成立返回真。

- 语法:`[ 整数1 -gt 整数2 ]`（注意 `[` 后、`]` 前要留空格）
- 常用运算符:

| 运算符 | 含义 |
|--------|------|
| `-eq` | 等于 |
| `-ne` | 不等于 |
| `-gt` | 大于 |
| `-ge` | 大于等于 |
| `-lt` | 小于 |
| `-le` | 小于等于 |

- 示例:

```bash
a=10
b=20
[ "$a" -gt "$b" ] && echo "a 大于 b"        # 不成立，不输出
[ "$a" -lt "$b" ] && echo "a 小于 b"        # 输出：a 小于 b
[ "$a" -eq 10 ] && echo "a 等于 10"         # 输出：a 等于 10
[[ "$a" -ne "$b" ]] && echo "a 不等于 b"    # 输出：a 不等于 b
```

### 字符串比较

> 比较两个字符串是否相等，或判断字符串是否为空。

- 语法:`[ "$s" = "值" ]`（变量建议加双引号，防止为空时报错）
- 常用运算符:

| 运算符 | 含义 |
|--------|------|
| `=` | 等于 |
| `!=` | 不等于 |
| `-z` | 长度为 0（为空） |
| `-n` | 长度非 0（非空） |

- 示例:

```bash
s="hello"
[ "$s" = "hello" ] && echo "相等"   # 输出：相等
[ "$s" != "world" ] && echo "不等"  # 输出：不等
[ -z "$s" ] && echo "为空"          # 不成立，不输出
[ -n "$s" ] && echo "非空"          # 输出：非空
```

### 逻辑运算

> 用逻辑运算符组合多个条件，构成更复杂的判断。

- 语法:`条件1 && 条件2` · `条件1 || 条件2` · `! 条件`
- 常用运算符:`&&` 与 · `||` 或 · `!` 非
- 示例:

```bash
a=10
[ "$a" -gt 5 ] && [ "$a" -lt 20 ] && echo "5 < a < 20"   # 输出：5 < a < 20
[ "$a" -eq 5 ] || [ "$a" -eq 10 ] && echo "a 是 5 或 10"  # 输出：a 是 5 或 10
[ ! "$a" -eq 0 ] && echo "a 不为 0"                       # 输出：a 不为 0
```

## 4. 流程控制

### if 条件判断

> 根据条件是否成立，执行不同的代码分支。

- 语法:

```bash
if 条件; then
    命令
elif 条件2; then
    命令
else
    命令
fi
```

- 说明:条件常用 `[ ]`、`[[ ]]`，或直接跟命令（退出码 0 为真、非 0 为假）
- 示例:

```bash
n=10
if [ "$n" -gt 0 ]; then
    echo "正数"
elif [ "$n" -lt 0 ]; then
    echo "负数"
else
    echo "零"
fi
```

### case 多分支

> 根据变量的值匹配多个分支，比一连串 `if` 更清晰。

- 语法:

```bash
case 值 in
    模式1) 命令 ;;
    模式2) 命令 ;;
    *)     默认命令 ;;
esac
```

- 示例:

```bash
read -p "输入 y/n: " ans
case "$ans" in
    y|Y) echo "是" ;;
    n|N) echo "否" ;;
    *)   echo "无效输入" ;;
esac
```

### for 循环

> 遍历一组值或文件，逐个执行命令。

- 语法:

```bash
for 变量 in 值1 值2 值3; do
    命令
done
```

- 说明:列表可以是多个值，也可以用通配符（如 `*.txt`）
- 示例:

```bash
for i in 1 2 3; do
    echo "第 $i 次"
done

for f in *.txt; do
    echo "处理 $f"
done
```

### while 循环

> 条件成立时反复执行，直到条件为假。

- 语法:

```bash
while 条件; do
    命令
done
```

- 示例:

```bash
i=1
while [ "$i" -le 5 ]; do
    echo "$i"
    i=$((i + 1))
done
```
