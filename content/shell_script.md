## 1. 脚本基础

### 脚本首行 (Shebang)

> 脚本第一行，用 `#!`（shebang）指定用哪个解释器执行。

- 语法:`#!/bin/bash`
- 常见写法:

| 写法 | 说明 |
|------|------|
| `#!/bin/bash` | bash 解释器（最常用） |
| `#!/bin/sh` | sh 解释器（更兼容，功能少） |
| `#!/usr/bin/env bash` | 从 PATH 里找 bash（更可移植） |

- 示例:

```bash
#!/bin/bash
echo "hello"
```

### 定义变量

> 自定义变量，注意 `=` 两边不能有空格。

- 语法:`变量名=值`
- 命名规则:字母或下划线开头，只能含字母、数字、下划线，区分大小写
- 只读变量:`readonly 变量名=值`，定义后不能再修改
- 示例:

```bash
name="zhangsan"
age=18
dir=/home/user
readonly PI=3.14          # 只读变量，之后不能改
```

### 获取变量值

> 用 `$` 读取变量的值。

- 语法:`$变量名` 或 `${变量名}`
- 常用特殊变量:`$0` 脚本名 · `$1` 第1个参数 · `$#` 参数个数 · `$?` 上条命令退出码 · `$$` 当前进程 PID
- 示例:

```bash
echo $name
echo "${name}abc"       # 花括号界定变量名，避免歧义
echo "第一个参数: $1"
```
